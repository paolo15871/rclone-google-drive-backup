Rclone Google Drive Backup

Questa pagina descrive un'applicazione OAuth destinata all'utilizzo personale per effettuare copie di backup di file Google Drive tramite Rclone.

Funzionamento

L'applicazione utilizza le API Google Drive esclusivamente per leggere e scaricare file autorizzati dall'utente.

L'accesso ai dati avviene in sola lettura. L'applicazione non modifica né elimina i documenti presenti su Google Drive.

Gestione dei dati

I file vengono copiati direttamente sul dispositivo di archiviazione scelto dall'utente.

Non viene utilizzato alcun server applicativo per raccogliere o conservare i documenti.

Per maggiori informazioni consulta l'informativa sulla privacy.
